# Travaux existants recensés

- [Ku, Execution Governance v1.0.1](https://zenodo.org/records/20583103): pre-execution authorization and mapping to existing frameworks. Read from abstracts only.
- [AIREP, AI Runtime Evidence Protocol](https://huggingface.co/papers/2608.21363): one signed record per runtime decision, verifiable offline.
- [PCAA, Proof-Carrying Agent Actions](https://awesomepapers.io/papers/2606.04104): five checkpoints and replay-ready proof.
- [arXiv 2604.05229, From Governance Norms to Enforceable Controls](https://arxiv.org/pdf/2604.05229): layered translation of ISO and NIST into runtime guardrails.
- [arXiv 2603.16586, Runtime Governance for AI Agents: Policies on Paths](https://arxiv.org/pdf/2603.16586): compliance policies as functions on execution paths.
