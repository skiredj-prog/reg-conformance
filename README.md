# REG Conformance (`reg-conformance`)

Cadre et outillage de conformité pour le protocole **REG (Runtime Execution Governance)**.

---

## 🚀 Accès Rapide & Adoptabilité

| Profil | Lien d'accès | Description |
| :--- | :--- | :--- |
| 🌐 **Utilisateurs & Décideurs** | [**Interface Interactive Crosswalk**](https://skiredj-prog.github.io/reg-conformance/crosswalk/) | Explorer, filtrer et exporter la correspondance terminologique (CSV). |
| 🤖 **Développeurs & Agents** | [**`crosswalk.json` (Raw)**](https://raw.githubusercontent.com/skiredj-prog/reg-conformance/main/crosswalk/data/crosswalk.json) | Consommer la base de données de correspondance via API/CI/CD. |
| 📝 **Contributeurs** | [**Proposer une PR**](https://github.com/skiredj-prog/reg-conformance/edit/main/crosswalk/data/crosswalk.json) \| [**Ouvrir une Issue**](https://github.com/skiredj-prog/reg-conformance/issues/new) | Contribuer, corriger ou valider un alignement normatif. |

---

## 📚 Structure du Dépôt

* **`crosswalk/`** : Module de correspondance terminologique et de conformité réglementaire (NIST, ISO/IEC 42001, EU AI Act).
  * [`crosswalk/README.md`](crosswalk/README.md) : Guide pédagogique, méthodologie et taxonomie des relations.
* **`vectors/`** : Catalogue source des vecteurs de conformité pour l'exécution REG.
