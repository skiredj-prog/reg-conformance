# PROOF-01 / W4.3 — Native B3 evidence adapter and differential oracle (candidate v0.1)

**Status:** Laboratory / Draft / Non-certifying. **No release, no conformance promotion.**

## Purpose

Import **native evidence**, not reconstructed synthetic authority, from the B3 ↔ REG-RC-01 ↔ I8 laboratory. W4.2's `proof01-signed-events/1` wire contract remains an *independent, synthetic* fixture with runtime/provider/witness event signatures. The **real laboratory kit does not produce those signed runtime events**, and W4.3 MUST NOT forge, re-sign, or silently map unsigned events into that contract.

### Inputs

A `proof01-w4/1` manifest referencing native artifacts by SHA-256:

- `provider-bundle.json`: native B3 terminal receipt, Ed25519 signature, Merkle inclusion and signed checkpoint;
- `local-state.json`: unsigned lab RC-01 transition log and I8 accounting snapshot;
- `witness-events.json`: lab hash-linked witness events;
- `--pins /external/path/operator-pins.json`: separately supplied **operator-generated** provider key, signed checkpoint SHA and witness tip. It is not sufficient to claim third-party independent custody.

Native format version is `proof-provider-bundle/candidate-v0.1`. Exact field mappings and canonical JSON are taken from the frozen 2026-10-26 lab export. **The lab canonicalizer is not standardized RFC-8785/JCS.** Reject mismatched versions. No transformation of these observations into Ed25519-signed W4.2 events is allowed.

### Two readers

1. `native_b3.py`: independent of TENIR-Gov producer, checks receipt signatures, Merkle, pinned checkpoint, witness hash chain, RC-01/I8 single-operation history, grant presence, tau deadline and local effect binding.
2. `native_oracle.py`: separately implemented, intentionally restricted, independently recomputes provider signature/Merkle, witness pin and core budget and state equalities for the **same one-operation synthetic case**.

`adapt_native.py` compares the outcomes and reports `INDETERMINATE` on disagreement. An aligned `VERIFIED` is **strictly** limited to *the recorded single-operation lab snapshot's coherence relative to operator-provided pins*. It is **not** evidence of G4-A execution, completeness of external effects, a valid real grant, third-party independent anchoring, privileged-writer resistance, or real banking behavior.

The test corpus includes SHA inventory mutation, rehashed forged receipt, signature substitution, wrong provider checkpoint, missing evidence, witness tail rollback, inconsistent I8 totals and duplicate settlement. Each asserts both readers' verdict category, rather than assuming that test process PASS implies security PASS.

### Open cross-component gates

- **W2 G4-A:** no native G4-A/B3 integration evidence or fixed end-to-end SUT SHA in this package.
- **W3 B1/B2:** direct bypass, same-UID database tampering, Q1, Q6 and R-01 remain OPEN.
- **W4 B4:** provider and witness pins were generated by a local operator; true independent custody and observation completeness remain unproven.
- **Conformance:** RFC-7 vectors are candidates; no normative ratification or deployment certification.

### Usage

From directory containing `proof01_w4/`:

```bash
python -m pip install 'cryptography>=43,<47'
python -m unittest discover -s proof01_w4/tests -v
python -m proof01_w4.adapt_native proof01_w4/testdata/native_b3/bundle \
  --pins proof01_w4/testdata/native_b3/external_trust/operator-pins.json
```

The two readers share inputs and a reference scenario but **not implementation code or producer imports**. They are not institutionally independent; a common mistaken field mapping remains possible.
